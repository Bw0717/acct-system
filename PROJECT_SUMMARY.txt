================================================================================
                             快速開始步驟
================================================================================

1️⃣  數據庫準備（5 分鐘）
    sqlplus admin/password@connection
    @sql/income_tables.sql
    DESC "ADMIN"."INC_INCOME_MAIN";

2️⃣  環境配置（2 分鐘）
    確認 .env.local 包含：
    - DB_USER
    - DB_PASSWORD
    - DB_CONNECTION_STRING

3️⃣  本地測試（10 分鐘）
    npm run dev
    訪問 http://localhost:5173
    登入系統 → 進入「收入記帳」 → 測試功能

4️⃣  部署上線（15 分鐘）
    按 DEPLOYMENT_CHECKLIST.md 檢查
    npm run build
    vercel deploy --prod

總時間：≈ 30 分鐘
