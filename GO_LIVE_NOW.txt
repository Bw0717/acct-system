================================================================================
                  ⏰ 第 3 步：配置 Vercel（2 分鐘）
================================================================================

1. 訪問：https://vercel.com/chiens-projects-4b898278/acct-system

2. 進入 Settings → Environment Variables

3. 添加 3 個環境變量：
   DB_USER = admin
   DB_PASSWORD = 你的Oracle密碼
   DB_CONNECTION_STRING = 你的Oracle連接字符串

4. 對所有環境勾選：Production, Preview, Development

5. 進入 Settings → Git → Connected Git Repository

6. 點擊「Connect Repository」→ 選擇 acct-system

7. 確認部署設置：
   - Production Branch: main
   - Build Command: npm run build
   - Output Directory: dist

================================================================================
