================================================================================
                   🚀 Vercel 部署 - 簡明步驟
================================================================================

你的 Vercel 項目：
https://vercel.com/chiens-projects-4b898278/acct-system

================================================================================
                        ⏰ 3 分鐘快速部署
================================================================================

第 1 步：初始化 Git（在 PowerShell 中執行）
────────────────────────────────────────────────────────────────────────────

cd D:\acct-system
git init
git add .
git commit -m "feat: income module - ready for production"

（完成後你的代碼已提交到本地 Git）


第 2 步：連接到 GitHub（如果還沒有倉庫）
────────────────────────────────────────────────────────────────────────────

1. 訪問 https://github.com/new
2. 創建新倉庫：acct-system
3. 複製 SSH 或 HTTPS URL
4. 在 PowerShell 執行：

   git remote add origin https://github.com/你的用戶名/acct-system.git
   git branch -M main
   git push -u origin main

（完成後你的代碼已推送到 GitHub）


第 3 步：設置 Vercel 環境變量
────────────────────────────────────────────────────────────────────────────

1. 訪問：https://vercel.com/chiens-projects-4b898278/acct-system
2. 進入 Settings → Environment Variables
3. 添加以下變量：

   DB_USER=admin
   DB_PASSWORD=你的Oracle密碼
   DB_CONNECTION_STRING=你的Oracle連接字符串

4. 保存

（完成後 Vercel 可以連接你的數據庫）


第 4 步：連接 GitHub 倉庫（如果還未連接）
────────────────────────────────────────────────────────────────────────────

1. Vercel Dashboard → Settings → Git
2. 連接你的 GitHub 倉庫
3. 選擇 acct-system 倉庫
4. 確認部署設置：
   - Production Branch: main
   - Build Command: npm run build
   - Output Directory: dist

（完成後 Vercel 會監視你的 GitHub 倉庫）


第 5 步：推送代碼觸發部署
────────────────────────────────────────────────────────────────────────────

在 PowerShell 執行：

cd D:\acct-system
git push origin main

Vercel 會自動檢測到代碼變化並開始部署！


第 6 步：監控部署進度
────────────────────────────────────────────────────────────────────────────

訪問：https://vercel.com/chiens-projects-4b898278/acct-system/deployments

等待狀態變成「Ready」（通常 5-10 分鐘）


第 7 步：訪問你的應用
────────────────────────────────────────────────────────────────────────────

部署完成後訪問：
https://acct-system.vercel.app

或 Vercel 分配的其他域名。

================================================================================
                        🔧 常見問題快速解決
================================================================================

Q: 部署失敗，顯示「npm ERR!」
A: 本地執行 npm install，確認沒有錯誤，然後重新推送代碼

Q: 部署成功但無法訪問數據庫
A: 檢查環境變量是否正確，確認 Oracle 實例在線

Q: 頁面加載但無樣式
A: 清除 Vercel 緩存後重新部署

Q: 應用返回 401 Unauthorized
A: 確認已登入，檢查認證令牌有效期
